## :dart: O guia para alavancar a sua carreira

> Apache Cassandra é o banco de dados NoSQL distribuído que sustenta sistemas que não podem sair do ar: Netflix, Apple, Uber e milhares de outras empresas o usam para escrever e ler dados em escala planetária, sem ponto único de falha, replicando entre datacenters e regiões diferentes. Este guia reúne documentação oficial, ferramentas, livros, canais, comunidades e um capítulo dedicado a usar IA na prática com Cassandra — tudo verificado e organizado para quem já conhece bancos relacionais e quer entender como pensar em dados de forma distribuída, do primeiro `CREATE KEYSPACE` à operação de um cluster em produção.

## 🤖 IA na prática

Cassandra é um banco poderoso, mas com uma modelagem de dados bem diferente do relacional — e é justamente aí que um assistente de IA ajuda mais.

**Para aprender**
- Descreva o padrão de acesso da sua aplicação (ex.: "preciso buscar os últimos 50 pedidos de um cliente, ordenados por data") e peça para a IA sugerir a modelagem de tabela em CQL — no Cassandra, você modela a partir das queries, não das entidades.
- Peça para explicar, com exemplos, a diferença entre partition key e clustering key, e por que uma partição "quente" (muito grande ou muito acessada) é um problema real de performance.
- Cole um `cassandra.yaml` ou uma configuração de `nodetool status` e peça para a IA apontar sinais de desequilíbrio no cluster (nós com carga muito diferente, tokens mal distribuídos).
- Peça exercícios práticos de CQL (criar keyspace, tabela, índice SAI, consulta com `ALLOW FILTERING` e por que evitá-lo) com gabarito.

**Para trabalhar**
- Use [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) ou [Claude Code](https://code.claude.com/docs/en/overview) para gerar scripts de migração de schema, testes de integração com Testcontainers e consultas CQL a partir de uma descrição em linguagem natural.
- Peça para revisar uma modelagem de dados existente e apontar riscos: partições sem limite de crescimento, uso de `SELECT *` em produção, ausência de TTL onde fazia sentido.
- O Cassandra 5.0 trouxe **busca vetorial nativa** (Storage Attached Indexes + vector search): peça ajuda para desenhar um pipeline de RAG (Retrieval-Augmented Generation) usando Cassandra ou Astra DB como armazenamento de embeddings, com [LangChain](https://github.com/langchain-ai/langchain-community/blob/main/libs/community/langchain_community/vectorstores/cassandra.py) ou [LlamaIndex](https://developers.llamaindex.ai/python/framework/integrations/vector_stores/cassandraindexdemo/).

**Limites e boas práticas**
- IA erra fácil na modelagem de dados do Cassandra por hábito relacional (sugerir `JOIN`s, normalizar demais, ignorar a partition key). Sempre confira contra a [documentação oficial de modelagem](https://cassandra.apache.org/doc/latest/cassandra/developing/data-modeling/index.html).
- Nunca cole dados reais de produção, credenciais de cluster ou strings de conexão em ferramentas de IA sem a política de segurança da sua empresa.
- Rode `EXPLAIN` (via `nodetool` e logs de trace) e teste em um cluster local antes de aplicar qualquer sugestão de mudança de schema em produção — alterar uma partition key existente costuma exigir migração completa dos dados.
- Entenda o que aceita: você é responsável pelo schema e pelas queries que vão para produção.

**Para se aprofundar**

- [Vector Search no Cassandra 5.0 (oficial)](https://cassandra.apache.org/doc/latest/cassandra/vector-search/overview.html) — Documentação oficial da busca vetorial nativa, base para RAG (Retrieval-Augmented Generation) direto no Cassandra.
- [Astra DB para aplicações de IA (DataStax/IBM)](https://docs.datastax.com/en/astra-db-serverless/index.html) — Como usar o Cassandra gerenciado (Astra DB) como banco vetorial para aplicações de IA generativa.
- [LangChain — vector store do Cassandra (código-fonte)](https://github.com/langchain-ai/langchain-community/blob/main/libs/community/langchain_community/vectorstores/cassandra.py) — Implementação oficial do LangChain mostrando como usar o Cassandra como vector store em pipelines de IA.
- [LlamaIndex — integração com Cassandra](https://developers.llamaindex.ai/python/framework/integrations/vector_stores/cassandraindexdemo/) — Exemplo oficial de uso do Cassandra como armazenamento vetorial em aplicações RAG com LlamaIndex.
- [Model Context Protocol — site oficial](https://modelcontextprotocol.io/) — Protocolo aberto (lançado em 2024) para conectar assistentes de IA a ferramentas e dados — útil para expor um cluster Cassandra a um agente.
- [GitHub Copilot](https://github.com/features/copilot) — Autocomplete e chat com IA no editor; entende bem CQL e os principais drivers do Cassandra.
- [Claude Code](https://code.claude.com/docs/en/overview) — Agente de código no terminal, útil para gerar modelagem de dados, scripts de migração e testes de CQL.

## 🎓 Certificações

Não existe hoje uma certificação oficial de Cassandra mantida diretamente pela Apache Software Foundation (o projeto, como a maioria dos projetos Apache, não emite certificados).
